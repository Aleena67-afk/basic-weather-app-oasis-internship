# Basic Weather App

A basic weather app built with Python as part of my Oasis Infobyte internship.

## Features

- Search weather by city name
- Search weather using a Pakistani ZIP code
- Displays current weather information
- Displays weather forecast
- Uses OpenWeather API
- Simple Tkinter graphical interface

## Technologies Used

- Python
- Tkinter
- OpenWeather API
- Requests
- python-dotenv
